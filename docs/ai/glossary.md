# 术语表

一句话解释，按字母或拼音排序。

- **close-on-exec**：文件描述符上的一个标记，进程 exec 成新程序时自动关闭该描述符；fork 出来的子 shell 不 exec，所以仍然持有它。
- **deny 规则**：Claude Code 权限配置中的禁止项，优先级高于 allow，项目级和全局配置合并后仍然生效。
- **git mv**：让 git 把改动记录为「移动」，历史和 blame 可以追溯到原位置。
- **worktree**：同一仓库的另一个工作目录，可在其中检出别的分支；夜跑在独立 worktree 的新分支上工作，不碰当前分支。
- **标准输入重定向 `</dev/null`**：让程序读到的输入立即结束，不会等待键盘或上游管道。
- **进程组**：一组可以被一次性发送信号的进程；`set -m` 让后台任务自成一组，`kill -- -<组号>` 可以连同它的子进程一起结束。
- **看门狗**：和主命令一起启动的后台计时进程，超时就结束主命令；主命令先结束，它也随之退出。
- **命令替换 `$(...)`**：把命令输出收进变量，要等所有持有这个输出管道的进程都退出后才返回。
